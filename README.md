# 🎨 Color Palette Generator

### Generate. Explore. Get Inspired.

تطبيق تفاعلي لتوليد لوحات ألوان عشوائية باستخدام **Next.js** و**React**، يتيح للمستخدم استكشاف مجموعات متنوعة من الألوان وعرض أكوادها بصيغة HEX بسهولة.

---

## ✨ نبذة عن المشروع

تم تطوير هذا المشروع لتقديم تجربة بسيطة وسريعة لتوليد الألوان العشوائية، مع عرض كل لون داخل مربع مخصص وإظهار كود اللون المقابل له.

يجمع المشروع بين واجهة استخدام واضحة ومنطق برمجي يعتمد على توليد الألوان وتحديث واجهة المستخدم بشكل تفاعلي.

## 🚀 المميزات

* 🎨 توليد خمسة ألوان عشوائية عند الضغط على الزر.
* 🔄 تحديث لوحة الألوان بسهولة في كل مرة.
* 🔢 إنشاء ألوان عشوائية بصيغة HEX.
* 🖌️ عرض كل لون داخل مربع بلونه الفعلي.
* 🏷️ إظهار كود HEX الخاص بكل لون.
* ⚡ تحديث الواجهة مباشرة باستخدام React State.
* 📱 أساس مناسب للتطوير مستقبلًا وإضافة مزايا جديدة.

## 🛠️ التقنيات المستخدمة

* **Next.js** — إطار عمل React لتطوير تطبيقات الويب.
* **React** — لبناء واجهة المستخدم وإدارة الحالة.
* **JavaScript** — لتنفيذ منطق توليد الألوان.
* **JSX** — لكتابة واجهة المستخدم.
* **CSS Inline Styles** — لتطبيق ألوان الخلفيات وأبعاد مربعات الألوان.

## ⚙️ آلية العمل

1. تظهر لوحة تحتوي على خمسة ألوان افتراضية عند فتح الصفحة.
2. يضغط المستخدم على زر `Generate Colors`.
3. يُنشئ التطبيق خمسة ألوان عشوائية جديدة بصيغة HEX.
4. تُحدَّث حالة التطبيق باستخدام `useState`.
5. تعرض الواجهة لوحة الألوان الجديدة وأكوادها.

## 🧠 المفاهيم البرمجية التي يطبقها المشروع

* إدارة الحالة باستخدام `useState`.
* إنشاء الدوال واستدعاؤها وإرجاع القيم باستخدام `return`.
* توليد الأرقام العشوائية باستخدام `Math.random()` و`Math.floor()`.
* تحويل الأرقام إلى النظام السداسي عشر باستخدام `toString(16)`.
* تنسيق أكواد الألوان باستخدام `padStart()`.
* إنشاء المصفوفات باستخدام `Array.from()`.
* عرض عناصر المصفوفات باستخدام `map()`.
* التعامل مع أحداث المستخدم باستخدام `onClick`.
* تحديث واجهة المستخدم استجابةً لتغيّر الحالة.

## 🎯 الهدف من المشروع

يهدف المشروع إلى تطبيق مفاهيم JavaScript وReact عمليًا من خلال بناء أداة تفاعلية صغيرة، مع التركيز على توليد البيانات وتحديث واجهة المستخدم وعرض النتائج بصورة واضحة.

## 🔮 تطويرات مستقبلية محتملة

* إضافة زر لتثبيت الألوان المفضلة.
* توفير خيارات متعددة لتنسيقات الألوان.
* تحسين تصميم الواجهة وتجربة الاستخدام.
* إضافة تصميم متجاوب لمختلف أحجام الشاشات.
